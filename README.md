# AI Agent Frontend — Atlas

React + Vite + TypeScript starter with Tailwind CSS, shadcn/ui, TanStack Query and React Router.

## Getting started

Requirements: Node.js 22.12+ (tested with 22.23.1) and npm.

```sh
npm ci
npm run dev
```

Open the address printed by Vite in the terminal.

The login page is available at `/login`, also accessible through “Sign out” in the sidebar. It uses shadcn/ui components and remains a demo interface: submitting the form sends no credentials and displays a message explaining that authentication is not connected yet. “Explore the demo” returns to the dashboard.

## Data: fixtures or a real backend

By default, the app responds with the JSON fixtures in `src/api/fixtures/` (reloading resets the data).
The fixtures and mock server follow the backend contract: identical routes and request bodies, with JSON in snake_case.
To call FastAPI, create `.env.local` from `.env.example` and set `VITE_API_MOCK=false`.

`src/api/client.ts` converts keys between snake_case and camelCase and sends the JWT (`Authorization: Bearer`),
read from `localStorage` or from `?token=` on the SSO callback.

## Project structure

- `src/pages/`: Dashboard, Projects (list), Project (`/projects/:projectId/:tab?`), Kanban (`?project=` to filter, `?view=list` for list view), Journal (`?project=`, `?us=`, `?actor=`, `?action=` to filter), Profile (`/profile`), Settings, Login and 404 pages.
- `src/components/layout/`: layout, shadcn/ui sidebar and page header.
- `src/components/projects/`: project page tabs (sources, members, Jira fields, context) and dialogs (new project, users, deletion).
- `src/components/kanban/`: “New US” form, user story detail panel (one tab per stage, comments, approval, chat), coding agent session (`coding-agent.tsx`) and type, priority and stage icons.
- `src/components/markdown.tsx`: rendering of Markdown documents generated by agents.
- `src/components/source-badge.tsx`: Jira, Confluence and GitLab source badges.
- `src/components/ui/`: shadcn/ui components that can be edited within the project.
- `src/api/endpoints.ts`: one function per FastAPI backend route.
- `src/api/hooks.ts`: TanStack Query hooks used by the screens.
- `src/api/client.ts`: HTTP requests to the backend or mock server, depending on `VITE_API_MOCK`.
- `src/api/mock-server.ts` and `src/api/fixtures/*.json`: in-memory mock backend with the same routes as FastAPI.
- `src/lib/domain.ts`: API types and workflow constants.
- `src/lib/diff.ts`: line-by-line diff used for refinement before/after comparisons.
- `src/lib/story-workflow.ts`: mapping between columns and stages.
- `src/lib/query-client.ts`: TanStack Query cache configuration.
- `src/lib/utils.ts`: styling utilities.
- `src/App.tsx`: route definitions.
- `src/main.tsx`: React Router and TanStack Query providers.
- `src/index.css`: Tailwind and shadcn/ui theme.

The `@/` alias points to `src/`. TypeScript runs in strict mode.

The frontend runs on its own in demo mode. API calls target an external FastAPI backend; this repository does not contain the backend. The Profile page displays the signed-in account and its projects, and allows changing its role through `PATCH /auth/me`.

To add a component:

```sh
npx shadcn@latest add input
```

When hosting, redirect unknown URLs to `index.html` to support direct navigation to React Router routes.

Documentation: [shadcn/ui with Vite](https://ui.shadcn.com/docs/installation/vite), [React Router](https://reactrouter.com/start/declarative/installation), [TanStack Query](https://tanstack.com/query/latest/docs/framework/react/overview).
